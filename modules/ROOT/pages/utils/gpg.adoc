Для подписывания файлов широко используется утилита `gpg`.

Чтобы отобразить все доступные подписи, используйте следующую команду:

== Подпись файла

Разберем необходимые флаги для подписания файла

-a, --armor::
Вместо бинарного формата используется текстовый на основе символов ASCII, который можно передавать на другие устройства.

-o, --output <FILENAME>::
Записать подпись в соответствующий файл

-s, --sign::
Подписать файл

-b, --detach-sign::
Не включать исходный файл в вывод

--clear-sign::
Вывести в формате cleartext подпись

Попробуем подписать файл:

[,console]
----
$ echo 1234567890 > msg.txt
$ gpg -abs msg.txt
$ ls
msg.txt  msg.txt.asc
$ gpg --clear-sign msg.txt
File 'msg.txt.asc' exists. Overwrite? (y/N) N
Enter new filename: msg.txt.asc.1
$ cat msg.txt.asc

== Проверка подписи

Для проверки необходимо сначала подгрузить публичный ключ. Пусть экспортированный публичный ключ лежит в `key.pub`, тогда достаточно выполнить следующие команды:

[,console]
----
$ gpg --import key.pub
gpg: key C9EA16EA9EB1D164: public key "My Name (some info) <add@example.com>" imported
gpg: Total number processed: 1
gpg:               imported: 1
$ gpg --verify msg.asc
gpg: Signature made Mon 10 Aug 2026 16:57:13 MSK
gpg:                using EDDSA key 0423BE53A529AC081FD0F131C9EA16EA9EB1D164
gpg: Good signature from "My Name (some info) <add@example.com>" [unknown]
gpg: WARNING: This key is not certified with a trusted signature!
gpg:          There is no indication that the signature belongs to the owner.
Primary key fingerprint: 0423 BE53 A529 AC08 1FD0  F131 C9EA 16EA 9EB1 D164
----
