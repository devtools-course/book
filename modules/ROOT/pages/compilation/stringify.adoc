== Оператор `#`: стрингификация

Одиночная решётка перед параметром макроса превращает аргумент *в строковый литерал*, буквально в том виде, как он написан в исходнике.

[,cpp]
----
#define STRINGIFY(x) #x

const char* s = STRINGIFY(2 + 2);   // получится "2 + 2", а не "4"
----

Самое частое применение - самодельные assert и логирование, где нужно показать выражение как текст:

[,cpp]
----
#define CHECK(cond)                                            \
    do {                                                       \
        if (!(cond)) {                                         \
            std::cerr << "Проверка провалилась: " #cond        \
                      << " в " << __FILE__ << ":" << __LINE__; \
            std::abort();                                      \
        }                                                      \
    } while (0)

CHECK(size > 0);   // при падении напечатает: Проверка провалилась: size > 0
----

Тонкость: `#` не разворачивает макросы в аргументе. Если написать `STRINGIFY(MAX_SIZE)`, получится строка `"MAX_SIZE"`, а не `"1024"`. Лечится классическим двойным макросом:

[,cpp]
----
#define STRINGIFY_IMPL(x) #x
#define STRINGIFY(x) STRINGIFY_IMPL(x)     // сначала развернёт x, потом застрингифицирует

#define VERSION 42
const char* v = STRINGIFY(VERSION);        // теперь "42"
----

Причина в правилах препроцессора: аргументы макроса разворачиваются перед подстановкой, *кроме* тех, к которым применяются `#` или `##`. Лишний слой макроса даёт аргументу шанс развернуться до того, как до него доберётся решётка.

== Оператор `##`: склейка токенов

Двойная решётка склеивает два токена в один. Не строки, а именно токены: результат должен быть корректным идентификатором или числом.

[,cpp]
----
#define CONCAT(a, b) a##b

int CONCAT(my, Var) = 5;    // объявит переменную myVar
----

Практическое применение - генерация уникальных имён и однотипных объявлений:

[,cpp]
----
#define UNIQUE_NAME(prefix) CONCAT(prefix, __LINE__)

#define DECLARE_GETTER(type, name)      \
    private:                            \
        type name##_;                   \
    public:                             \
        type Get##name() const { return name##_; }

class Point {
    DECLARE_GETTER(int, X)    // развернётся в поле X_ и метод GetX()
    DECLARE_GETTER(int, Y)
};
----
