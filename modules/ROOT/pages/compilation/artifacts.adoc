== Какие файлы получаются

[cols="1,2,3"]
|===
|Расширение |Что это |Чем смотреть

|`.c`
|Исходник на C
|любой редактор

|`.cpp`, `.cc`, `.cxx`, `.C`
|Исходник на C++
|любой редактор

|`.h`
|Заголовочный файл (C или C++)
|любой редактор

|`.hpp`, `.hh`, `.hxx`
|Заголовочный файл, явно C++
|любой редактор

|`.i`
|Препроцессированный C
|редактор, там текст

|`.ii`
|Препроцессированный C++
|редактор, там текст

|`.s`, `.S`
|Ассемблер (`.S` - ещё не препроцессированный)
|редактор, там текст

|`.o`, `.obj`
|Объектный файл, бинарь
|`nm`, `objdump`, `readelf`, `xxd`

|`.a`
|Статическая библиотека (архив объектников)
|`ar t`, `nm`

|`.so`, `.so.1.2.3`
|Динамическая библиотека
|`nm -D`, `ldd`, `readelf`

|`a.out`, без расширения
|Исполняемый файл
|`file`, `ldd`, `objdump`
|===

Имя `a.out` расшифровывается как *assembler output* и досталось нам из семидесятых. Сегодня формат называется ELF, а имя осталось: если не передать `-o`, `gcc` до сих пор назовёт результат именно так.
